# Android\-Marcos

Aplicación Android desarrollada en Kotlin para la gestión de animes.

## Descripción

Esta aplicación permite gestionar una colección de animes mediante operaciones de inserción, consulta y eliminación de registros almacenados en una base de datos local.

## Funcionalidades

- Añadir nuevos animes.
- Consultar animes almacenados.
- Eliminar animes.
- Persistencia de datos local.
- Interfaz gráfica desarrollada para Android.

## Tecnologías utilizadas

- Kotlin
- Android Studio
- Room Database
- RecyclerView
- Material Design
- Gradle

## Estructura del proyecto

- Activities
- Adapter
- Base de datos Room
- Recursos XML
- Tests unitarios
